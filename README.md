# Nordic Real Estate Advisory Dashboard

A lightweight, single-file web dashboard built for real estate advisory professionals. No installation needed — just open `index.html` in your browser.

## Features

- **Overview Dashboard** — KPIs at a glance: active deals, pipeline value, recent decisions
- **Property Yield Calculator** — Gross yield, net yield, NOI, and cash-on-cash return analysis
- **Mortgage Calculator** — Annuity and linear loan scenarios with total interest breakdown
- **Deal Pipeline Tracker** — Track advisory mandates through prospect, active, negotiation, and closed stages
- **Decision Log** — Record strategic decisions, market insights, action items, and meeting notes
- **Tech & PropTech Trends** — Curated reference on technology trends shaping Nordic real estate

## How to Use

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge)
2. No server, no installation, no account needed
3. Your deal pipeline and decision log are saved automatically in your browser's local storage

## Data Privacy

All data stays on your device — nothing is sent to any server. Data persists between sessions via browser local storage.
