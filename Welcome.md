# Welcome to your Obsidian Vault

This repository is configured as an Obsidian vault. You can open this folder directly in Obsidian.

## Getting Started

1. Open Obsidian
2. Select **Open folder as vault**
3. Choose this repository's folder

## Structure

- `attachments/` - Images and other file attachments
- `.obsidian/` - Vault configuration (synced via git)

## Existing Files

This vault also contains a web application project:
- `index.html` - Main HTML page
- `styles.css` - Stylesheets
- `app.js` - Application logic
